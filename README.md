# Toronto Address Repository Power BI Dashboard

An interactive Power BI dashboard to analyze and visualize over 500,000 address points from the Toronto One Address Repository dataset.

**Note:** The original dataset from the City of Toronto's Open Data portal has been retired. This project is intended for demonstration and archival purposes.

## 🚀 Features

- **Interactive Map:** Explore address points across the city of Toronto on an interactive map.
- **Data Filtering:** Filter addresses by street, postal code, and other attributes.
- **Geospatial Analysis:** Visualize address distribution, street patterns, and geospatial trends.
- **Summary Statistics:** View key statistics about the address data.

## 📊 Visualizations

The dashboard includes a variety of visualizations to explore the data:

- **Map:** A map showing the location of each address point.
- **Bar Charts:** Charts showing the number of addresses per street and postal code.
- **Tables:** Detailed tables of the address data.

## 💿 Dataset

The dataset used in this project is the **Address Points (Municipal) - Toronto One Address Repository**, which was formerly available on the [City of Toronto Open Data Portal](https://open.toronto.ca/dataset/address-points-municipal-toronto-one-address-repository/).

The dataset contains over 500,000 address points in the city of Toronto, with attributes such as:

- Street Name
- Street Number
- Postal Code
- Longitude
- Latitude

## 🔧 How to Use

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/<your-username>/Toronto-Address-Repository-PowerBI.git
    ```
2.  **Download the dataset:**
    - Since the original dataset is retired, a copy of the data (if available) would be in the `data/` directory.
3.  **Open the dashboard:**
    - The Power BI project file (`.pbix`) is located in the `dashboard/` directory.
    - Open the file in Power BI Desktop to view and interact with the dashboard.
