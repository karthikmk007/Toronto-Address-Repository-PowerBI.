# Toronto Address Analysis — Power BI

A data-visualization project exploring Toronto address records with Power BI.

## Purpose

The project is intended to help users examine address distribution, street patterns, and geographic trends across Toronto through an interactive dashboard.

## Current repository contents

This repository currently documents the project concept. Before treating it as a finished portfolio case study, add the following:

- the Power BI `.pbix` file or a public Power BI report link;
- two or three dashboard screenshots;
- the exact City of Toronto dataset link and access date;
- documented Power Query transformations and calculated measures;
- validated record counts and key findings.

## Suggested case-study structure

1. Define the business or civic question.
2. Describe the source data and data-quality checks.
3. Explain the data model and transformations.
4. Show the dashboard and its filters.
5. Summarize insights and limitations.
